# Client

Term: MQTT-SN Client (see the terminology section).

Sends: AUTH, CONNECT, CONNECTION ENCAPSULATION, DISCONNECT, PINGREQ, PROTECTION ENCAPSULATION, PUBACK, PUBCOMP, PUBLISH, PUBREC, PUBREL, PUBWOS, REGISTER, SEARCHGW, SLEEPREQ, SUBSCRIBE, UNSUBSCRIBE

Receives: ADVERTISE, AUTH, CONNACK, DISCONNECT, FORWARDER ENCAPSULATION, GWINFO, PINGRESP, PROTECTION ENCAPSULATION, PUBACK, PUBCOMP, PUBLISH, PUBREC, PUBREL, PUBWOS, REGACK, SLEEPRESP, SUBACK, UNSUBACK, WAKEUP
